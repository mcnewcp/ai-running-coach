## Directory Purposes

**ai-running-coach/ (root)**
- Purpose: Project root containing all coaching system materials
- Contains: System context (CLAUDE.md), CLI configuration (.claude/), planning artifacts (.planning/), and active/future training programs
- Key files: `CLAUDE.md` (the foundational coaching system context)

**.claude/**
- Purpose: Claude CLI configuration and GSD (Get Shit Done) framework
- Contains: Settings, hooks, 27 command definitions, 10 agent roles, workflow templates
- Key files: `settings.json` (permissions/hooks), `commands/gsd/` (command implementations), `agents/` (role definitions)
- Special: This is the infrastructure for the coaching orchestration system - allows `/gsd:` commands

**.planning/codebase/**
- Purpose: Codebase analysis documents generated by mapping commands
- Contains: ARCHITECTURE.md, STRUCTURE.md, CONVENTIONS.md, TESTING.md, STACK.md, INTEGRATIONS.md
- Key files: This directory (generated docs for future Claude instances)
- Generated by: `/gsd:map-codebase` command with different focus areas

**2026-music-city-half/**
- Purpose: Complete training program for Music City Half Marathon (April 25, 2026)
- Contains: Master plan, phase-specific plans, weekly logs, resource protocols
- Key files: `plans/master-plan.md` (16-week structure), `plans/phase-1-base.md` (current phase), `logs/week-##.md` (daily execution)
- Timeline: 16 weeks (Jan 6 - Apr 25, 2026)

**2026-music-city-half/plans/**
- Purpose: Training plans at macro (16-week) and micro (4-6 week phase) levels
- Contains: Phase plans with week-by-week detail, workout descriptions, mileage progression
- Key files: `master-plan.md` (entry point), `phase-1-base.md` (referenced during daily coaching)
- Pattern: Master plan links to phase plans; each phase plan has detailed week breakdowns

**2026-music-city-half/logs/**
- Purpose: Execution logs recording actual training completed and real-time metrics
- Contains: Morning metrics (sleep, HR, pain, energy), workout completions (distance, time, pace), subjective response, modifications, weekly summaries
- Key files: `00-baseline.md` (Jan 5 baseline), `week-01.md` through `week-04.md` (current logs)
- Pattern: New week-##.md file created Monday of each week; entries added daily

**2026-music-city-half/resources/**
- Purpose: Reference protocols and detailed procedures for training components
- Contains: HSR session templates with exercises/reps/weights, mobility routines with step-by-step instructions
- Key files: `hsr-protocols.md` (35-45 min session template), `mobility-routines.md` (pre-run, post-run, standalone routines)
- Usage: Consulted during daily coaching to prescribe specific exercises and sequences

## Key File Locations

**Entry Points:**
- `CLAUDE.md`: System context - read first by every Claude coaching session (defines mission, philosophy, runner profile, workflow rules, red flags)
- `2026-music-city-half/plans/master-plan.md`: 16-week training structure - referenced to understand phases and timelines
- `.claude/commands/gsd/map-codebase.md`: Codebase mapping command - executed by `/gsd:map-codebase` to generate planning docs

**Configuration:**
- `.claude/settings.json`: CLI permissions and hook configuration (defines allowed commands, statusline display)
- `CLAUDE.md`: Coaching system configuration (runner profile, medical constraints, training philosophy, daily workflow)

**Core Logic:**
- `2026-music-city-half/plans/phase-1-base.md`: Current phase plan with week-by-week detail - **THIS is what Claude reads during daily coaching to find today's workout**
- `2026-music-city-half/plans/master-plan.md`: Macro structure showing all 4 phases, mileage progression, weekly template
- `2026-music-city-half/resources/hsr-protocols.md`: HSR session prescriptions (exercise list, weights, reps, tempo, rest)
- `2026-music-city-half/resources/mobility-routines.md`: Mobility prescriptions (pre-run sequences, post-run stretches, deep mobility)

**Testing/Logging:**
- `2026-music-city-half/logs/00-baseline.md`: Baseline assessment with current fitness, injury status, biometrics
- `2026-music-city-half/logs/week-##.md`: Weekly logs (format: structured daily entries with metrics, completions, modifications)

## Naming Conventions

**Files:**
- Phase plans: `phase-{number}-{name}.md` (e.g., `phase-1-base.md`, `phase-2-build.md`)
- Weekly logs: `week-{number:two-digit}.md` (e.g., `week-01.md`, `week-16.md`)
- Baseline log: `00-baseline.md`
- Resource guides: `{component}-{type}.md` (e.g., `hsr-protocols.md`, `mobility-routines.md`)
- GSD commands: `{action}-{noun}.md` (e.g., `map-codebase.md`, `plan-phase.md`)

**Directories:**
- Training program: `{year}-{race-name}/` (e.g., `2026-music-city-half/`)
- Subdirectories: `plans/`, `logs/`, `resources/` (fixed structure per training program)
- CLI config: `.claude/` (hidden directory for framework config)
- Planning artifacts: `.planning/` (hidden directory for analysis output)

## Where to Add New Code

**New Training Program:**
1. Create directory: `/Users/coymcnew/code/ai-running-coach/{year}-{race-name}/`
2. Create subdirectories: `plans/`, `logs/`, `resources/`
3. Create baseline: `logs/00-baseline.md` (runner fitness at start of program)
4. Create master plan: `plans/master-plan.md` (16-week structure, mileage progression)
5. Create phase plans: `plans/phase-1-base.md`, etc. (week-by-week detail for each phase)
6. Create resource files: `resources/hsr-protocols.md`, `resources/mobility-routines.md` (protocols for this specific program)
7. Reference from: `.claude/settings.json` if adding new GSD commands for this program

**New Training Phase (mid-program):**
1. Create file: `2026-music-city-half/plans/phase-{number}-{name}.md`
2. Reference in: `2026-music-city-half/plans/master-plan.md` (add to phase breakdowns section)
3. Base structure: Use `phase-1-base.md` as template, adjust weeks, mileage ranges, workout types for new phase

**New Weekly Log:**
1. Create file: `2026-music-city-half/logs/week-{number:two-digit}.md` (e.g., `week-05.md`)
2. Include: Weekly training plan (from phase plan), daily log entries, weekly summary section
3. Timing: Create on Monday morning when coaching session starts
4. Format: Mirror existing week logs (00-baseline.md, week-01.md structure)

**New Resource Protocol:**
1. Create file: `2026-music-city-half/resources/{component}-{type}.md`
2. Include: Purpose statement, frequency/duration guidelines, step-by-step procedures with examples
3. Examples: `nutrition-guidance.md` (race fueling), `race-day-protocol.md` (hour-by-hour race morning)
4. Reference from: Phase plans, daily coaching sessions

**New GSD Command:**
1. Create file: `.claude/commands/gsd/{action}-{noun}.md`
2. Define: Command syntax, required inputs, workflow steps, expected outputs
3. Link from: `.claude/settings.json` (if adding new hook or permission)
4. Create agent if needed: `.claude/agents/gsd-{role}.md` (e.g., `gsd-race-analyzer.md`)

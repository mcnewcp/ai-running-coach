# Strength Training — General Movement-Pattern Framework

**Purpose**: A simple, durable, "don't-have-to-think-about-it" strength program built on the six fundamental movement patterns. Builds and maintains full-body strength to support running, posture, and long-term resilience.

**Adopted**: Jul 30, 2026 (Week 10 of the patellar rehab block), replacing the HSR + glute-med slot structure as the athlete's go-forward strength approach. See [hsr-protocols.md](hsr-protocols.md) for the rehab-specific HSR history and the still-active decline-squat test protocol.

This file is the durable, program-agnostic strength framework. Specific weekly loads/reps are recorded per-session in the active program's log file (see `data/current-goal.md`).

---

## The Six Movement Patterns

Every session is assembled from these fundamental patterns — pick one exercise per pattern slot, rotate exercises across weeks for variety.

| Pattern | Menu (rotate) |
|---|---|
| **Horizontal push** | Flat/incline DB or barbell bench, machine chest press, weighted push-up, dips |
| **Horizontal pull** | Chest-supported row, 1-arm DB row, seated cable row, barbell bent-over row, inverted row |
| **Vertical press** | Seated/standing DB shoulder press, barbell overhead press, machine shoulder press, landmine press, Arnold press |
| **Vertical pull** | Pull-up / chin-up (assisted as needed), lat pulldown (wide or neutral grip) |
| **Squat** | Back squat, goblet squat, leg press, **or unilateral:** split squat, walking lunge, step-up |
| **Hinge** | Trap-bar deadlift, RDL, conventional deadlift, **or unilateral:** single-leg RDL, B-stance RDL |

**Single-leg work lives inside the Squat and Hinge categories** — rotate a unilateral option in regularly. Running is a single-leg sport; unilateral strength is where a lot of injury-resilience lives.

**Optional finisher (never mandatory):** one of —
- **Core / anti-rotation / carry**: Pallof press, farmer/suitcase carry, hanging leg raise, ab-wheel, weighted plank
- **Arms superset**: biceps + triceps (antagonist pairing)
- **Glute-med insurance**: banded lateral walks, side-lying abduction, side plank *(carryover from the rehab block — kept as an optional 2-min add, not homework)*

## Weekly Structure (Mon / Wed / Fri)

Patterns are split so each lands **~2×/week** — the sweet spot for a general baseline — while keeping Monday upper-focused (recover from Sunday's long run), Wednesday lower, Friday a mix.

| Day | Focus | Slots |
|---|---|---|
| **Monday** | Upper | Horizontal push · Horizontal pull · Vertical press · Vertical pull *(+ optional finisher)* |
| **Wednesday** | Lower | Squat · Hinge · single-leg *(+ optional finisher)* |
| **Friday** | Mix | 1 push · 1 pull · 1 squat-or-hinge *(alternate with Wed's pick)* · *(+ optional slot)* |

### Default "no-thinking" lineup (rotate exercises when you want variety)

- **Mon:** DB bench → chest-supported row → DB shoulder press → lat pulldown *(+ optional arms)*
- **Wed:** Back squat *(controlled ~3s descent)* → trap-bar deadlift or RDL → split squat *(+ optional core)*
- **Fri:** Incline DB press → pull-ups / pulldown → goblet squat *or* RDL *(+ optional dealer's choice)*

## Loading & Progressive Overload — Double Progression

**The rule: add reps first, then add weight.** This is the entire progression system — no percentages, no math.

**Rep ranges (3 sets each):**
- **Mains** (all six patterns): **3 × 8–12**
- **Single-leg**: **3 × 8–12 per side**
- **Optional finishers**: **2–3 × 12–15**

**How it works:**
1. Pick a weight you can do for **3 × 8** with 1–2 reps in reserve (never grinding to failure).
2. **Each session, chase more reps** at that same weight — work the sets up toward the top of the range.
3. When you complete **the top of the range across all sets** (e.g., 3 × 12) cleanly with reps in reserve → **add the smallest load increment and drop back to the bottom** (3 × 8).
4. Repeat indefinitely. Slow and steady wins.

**Load increments when you graduate a lift:**
- **Upper / smaller lifts** (bench, press, rows, curls): **+2.5–5 lb** (next DB size up per hand)
- **Lower / bigger lifts** (squat, hinge, leg press): **+5–10 lb**

**Coach's role:** the athlete records loads/reps each session and reports back; the coach tracks the history in the log and **tells him when a lift has earned its load bump** (hit top of range, all sets, clean). He never has to remember where he is — the log does.

## Tempo & Form Notes

- **General tempo**: controlled, ~2s down / 1s up. No bouncing, no ego.
- **Squat exception (through the rehab block, and a good habit beyond it)**: **control the descent to ~3 seconds.** This bakes the tendon-remodeling benefit of HSR into a normal squat with zero extra thinking — the one carryover worth keeping from the rehab structure.
- **Reps in reserve**: leave 1–2 in the tank on mains. This is a sustainable baseline, not a powerlifting peak.
- **Respect niggles**: shoulder/elbow/knee twinges → swap the exercise within its pattern (e.g., swap barbell bench for DB or machine), don't push through.

## What to Track Each Session
- Exercise performed per pattern slot
- Working load × reps × sets (the athlete logs these; coach maintains the running history)
- Any pain/niggle or modification

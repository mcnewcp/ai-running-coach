# Upper Body Strength Menu — Complement to the HSR Lower-Body Work

**Purpose**: Balanced upper-body strength and hypertrophy to complement the lower-body HSR patellar-rehab work. Adds training variety, builds pressing/pulling strength, and supports posture and shoulder health (valuable for a desk-based remote worker and for running posture).

**This is NOT tendon-remodeling work.** The 6-second HSR tempo is specific to the lower-body knee-dominant and hip slots. Upper-body lifts use **normal controlled tempo** (~2s down, 1s up) and standard strength/hypertrophy rep ranges.

This file is the durable, program-agnostic upper-body framework, mirroring [hsr-protocols.md](hsr-protocols.md). Specific weekly scheduling lives in the active program's plan file (see `data/current-goal.md`).

---

## How it fits the week

Introduced Jul 1, 2026 as part of an upper/lower split (see the patellar rehab plan). Upper-body work appears on:

- **Monday** — dedicated upper-body day (all slots). Placed the day after the Sunday long run so tired legs get a running/HSR break while the upper body trains.
- **Friday** — mixed day: a subset of upper slots + the lower-body HSR core.

Roughly 1.5 upper-body sessions per week.

---

## Session Structure — Slot Template

Same philosophy as the lower menu: pick one item per slot, rotate across sessions for variety, log loads/reps to track progression.

### Slot U1 — Horizontal push
- Barbell bench press
- Dumbbell bench press (flat or incline)
- Machine chest press
- Weighted push-up
- Dips (chest-leaning)

### Slot U2 — Horizontal pull
- Barbell bent-over row
- Single-arm dumbbell row
- Chest-supported row (bench or machine)
- Seated cable row
- Inverted row (bar / rings)

### Slot U3 — Vertical push
- Barbell overhead press (standing)
- Dumbbell shoulder press (seated or standing)
- Landmine press
- Machine shoulder press
- Arnold press

### Slot U4 — Vertical pull
- Pull-up / chin-up (assisted or banded as needed)
- Lat pulldown (wide or neutral grip)
- Straight-arm pulldown (accessory variant)

### Slot U5 — Accessory superset (arms + shoulder health)
Pick a pairing; rotate so posture / rear-delt work shows up regularly.
- **Arms**: biceps (DB curl, hammer curl, cable curl) + triceps (cable pushdown, overhead extension, dips)
- **Shoulder / posture health**: face pulls, band pull-aparts, reverse flyes, external rotations

### Slot U6 (optional) — Core / carry
- Farmer or suitcase carry
- Hanging knee / leg raise
- Pallof press (anti-rotation)
- Ab-wheel rollout
- Weighted plank variations

*(Anti-rotation / trunk work here; the glute-med Copenhagen and side planks stay on the lower-body days.)*

## Loading & Progression

- **Tempo**: controlled, ~2s down / 1s up. No pause needed. This is normal lifting — the slow eccentric that remodels tendon is reserved for the lower-body knee/hip slots.
- **Rep ranges**:
  - Mains (U1–U4): **3–4 sets × 8–12**, leave 1–2 reps in reserve.
  - Accessories (U5–U6): **2–3 sets × 10–15**, control-focused.
- **Progression**: add load or reps when you complete all sets cleanly with reps in reserve — same rule as the lower menu.
- **No pain gating needed** for upper-body work (no patellar-tendon involvement), but respect any shoulder/elbow niggles the same common-sense way.

## Dedicated Monday (upper) vs. Friday (mix)

- **Monday (dedicated upper)**: hit U1–U5, add U6 if time. ~45–60 min.
- **Friday (mix)**: pick **2–3 upper slots** (typically one push + one pull + one accessory) alongside the **lower-body HSR core** (knee-dominant Slot 1 + hip hinge Slot 3 + one glute-med slot). Keep it to ~60–75 min. Rotate which upper slots you hit on Friday so that, across Mon + Fri, every upper pattern gets regular work.

## What to Track Each Session
- Exercises performed (which item from each slot)
- Working load and reps × sets
- Overall effort (RPE) and any modifications
